Turn any photo and caption into GTA VI-style cover art. NEON COAST is a
four-panel poster maker: one big hero photo on the left, three strips on the
right, over an orange-to-pink sunset band with bold Anton lettering, a script
subtitle, a gold VI badge and palm silhouettes.

Add your own photos, edit the title, subtitle and badge, pick a layout and a
colour grade, drag each panel to crop it, move the sliders, and export a
1280 × 720 PNG to share. Everything runs offline in the browser — photos
never leave your machine.

Built for the [make.fun gta6-cover-art-01 bounty](https://make.fun/bounty/gta6-cover-art-01).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
